## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/khushisharma25-oss/nova-ai-productivity-platform.git
```

### 2. Navigate to the project

```bash
cd nova-ai-productivity-platform
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run on the local Vite development server.

### 5. Build for production

```bash
npm run build
```

## 📱 Responsive Design

The website is designed for:

- Desktop
- Laptop
- Tablet
- Mobile

The layout adapts to different screen sizes using responsive CSS media queries and prevents unwanted horizontal scrolling.

## 🧩 Component Architecture

Each major section of the landing page is implemented as a separate React component.

Examples:

- `Navbar.jsx` — navigation and mobile menu
- `Hero.jsx` — main landing section
- `Features.jsx` — feature cards
- `Pricing.jsx` — pricing plans and billing toggle
- `FAQ.jsx` — expandable FAQ items
- `Stats.jsx` — animated statistics
- `ScrollReveal.jsx` — scroll-based animations

This component-based structure keeps the code organized, reusable, and maintainable.
